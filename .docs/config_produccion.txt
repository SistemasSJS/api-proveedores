# COMANDOS DE INSTALACIÓN Y CONFIGURACIÓN


## 1. Instalar dependencias

```bash
    composer install
```

## 2. Configurar entorno

```bash
    cp .env.example .env
    php artisan key:generate
```

## 3. Configurar base de datos

```bash
    php artisan migrate
    php artisan db:seed
```

## 4. Configurar storage

```bash
    php artisan storage:link
```

## 5. Optimizar para producción

```bash
    php artisan config:cache
    php artisan route:cache
    php artisan view:cache
    php artisan optimize
```

## 6. Configurar permisos

```bash
    chmod -R 775 storage
    chmod -R 775 bootstrap/cache
    chown -R www-data:www-data storage
    chown -R www-data:www-data bootstrap/cache
```
## 7. Configurar supervisor para colas (en producción)

```bash
    sudo nano /etc/supervisor/conf.d/laravel-worker.conf
```

### Contenido del archivo para las colas de ejecucion

```conf
    [program:laravel-worker]
        process_name=%(program_name)s_%(process_num)02d
        command=php /path/to/application/artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
        autostart=true
        autorestart=true
        stopasgroup=true
        killasgroup=true
        user=www-data
        numprocs=8
        redirect_stderr=true
        stdout_logfile=/path/to/application/worker.log
        stopwaitsecs=3600
```

# 8. Configurar cron para schedule

```bash
    sudo crontab -e
```

# Agregar:

```bash
    * * * * * cd /path/to/application && php artisan schedule:run >> /dev/null 2>&1
```

# 9. Configurar Nginx (ejemplo)

```
    server {
        listen 80;
        server_name tu-dominio.com;
        root /path/to/application/public;

        index index.php;

        location / {
            try_files $uri $uri/ /index.php?$query_string;
        }

        location ~ \.php$ {
            fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
            fastcgi_index index.php;
            fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
            include fastcgi_params;
        }
    }
```
